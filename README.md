# 🌍 Kpalimé-Trad

Plateforme numérique de référence de Kpalimé : commerce, tourisme, culture, artisanat, hébergement, restauration, événements et services locaux.

## 🛠️ Stack Technique

- **Framework** : Next.js (App Router)
- **Langage** : TypeScript
- **Base de données** : MongoDB Atlas + Mongoose
- **Médias** : Cloudinary (images & vidéos)
- **Style** : Tailwind CSS
- **Déploiement** : Vercel
- **Code** : GitHub

## 💱 Devises supportées

- XOF / FCFA (devise de base)
- USD / Dollar américain
- EUR / Euro
